# MVP 实施计划与验收

## 1. MVP 目标

首期交付一条真实可用的纵向闭环：用户上传一篇 PDF，系统解析引用，获取可用的开放引用全文，建立任务级临时索引，发现并展示可复核的文本复用证据，用户完成裁决并导出报告，最后确认临时资产处置结果。

统计、图片和复杂引文论断模块随后接入相同证据契约；不能为了展示检测器数量而牺牲第一条闭环。

## 2. 阶段 0：工程与契约骨架

交付：

- 建立 `apps/`、`packages/`、`services/`、`tests/` 基础结构。
- FastAPI、PostgreSQL、Redis、MinIO、GROBID的本地 Compose。
- `PaperTask`、`DocumentAsset`、`ReferenceSource`、`EvidenceItem`、`ReviewDecision`和`AuditEvent`首版模型。
- 任务状态机与幂等任务接口。
- 上传文件类型、大小、哈希、隔离路径和审计基础。

验收：

- 新任务能够上传真实 PDF并保存可回读的资产记录。
- 非法类型、超限文件和跨任务资产访问被拒绝且无副作用。
- Compose可从空环境启动，迁移可重复执行。

## 3. 阶段 1：解析、引用与临时语料

交付：

- GROBID完整论文解析。
- TEI到内部文档结构的稳定转换。
- Crossref/OpenAlex引用规范化。
- Unpaywall、CORE和学科开放仓库的全文获取适配器。
- 引用确认界面和覆盖率页面。
- 任务级存储与生命周期状态。

验收：

- 数字版和扫描版样本分别得到可检查的正文与页码映射。
- 引用清单能回到原始引用文本并显示解析置信度。
- 无 DOI、重复引用、元数据冲突、全文不可获得和下载损坏均有明确状态。
- 系统不会绕过付费墙或把失败记成成功。

## 4. 阶段 2：文本复用纵向闭环

交付：

- 文本规范化与原始位置映射。
- Winnowing/MinHash词面召回。
- BGE-M3 + FAISS语义召回。
- 候选重排和精确片段对齐。
- 双栏 PDF 证据查看、人工裁决和报告输出。
- 正确引用、直接引语、参考文献和通用方法短语的误报控制。

验收：

- 一项命中能从报告和界面准确回到待检与来源 PDF 的对应位置。
- 翻译或改写候选不会仅凭向量分数被标记为已确认抄袭。
- 正确引用和方法套话金标样本不会被呈现为高置信学术不端结论。
- 报告展示实际全文覆盖数、未取得列表和检测版本。

## 5. 阶段 3：引用真实性与论断支持

交付：

- 引用元数据、撤稿与更正检查。
- 论断—引用映射。
- 被引全文证据检索与支持关系分类。
- “全文不可获得”“未找到证据”“证据相反”的独立状态。

验收：

- 每个支持关系分类都带被引原文和位置。
- 移除模型解释后，审查者仍能依据原始证据理解该发现。
- 模型不可用时，元数据和规则检查仍可完成并如实降级。

## 6. 阶段 4：统计与数据模块

交付：

- 统计表达式与表格抽取。
- 隔离 R Worker及版本化输入输出契约。
- statcheck、GRIM/GRIMMER、SPRITE适用检查。
- 原始表格数据的安全读取和受控复算框架。

验收：

- 每项统计异常展示输入值、公式/工具、假设和复算结果。
- 不适用、缺少参数和解析失败不会被输出为异常。
- 已知数学一致与不一致金标样本均得到正确结果。

## 7. 阶段 5：图片模块

交付：

- 原图与页面渲染提取、面板映射。
- pHash/SSCD候选召回。
- 局部特征、几何验证和区域可视化。
- 待检论文与引用论文之间的任务内图片比对。

验收：

- 裁剪、旋转、压缩、缩放和镜像样本有分层测试。
- 纯相似候选与几何验证通过的证据分开呈现。
- 报告不在没有原图时声称认证了图片真实性。

## 8. 阶段 6：保留、权限与完整报告

交付：

- 任务与案件级权限。
- 用户可见保留选择和任务级清理。
- 清理失败的重试与审计。
- HTML/PDF完整报告及证据版本固定。

验收：

- 一个任务无法读取另一个任务的任何资产或证据。
- 清理后全文、索引和派生图片均按清单回读确认，审计信息符合策略。
- 报告和界面引用同一证据版本，页码、原文和裁决一致。

## 9. MVP 完成定义

以下条件全部满足才算 MVP 完成：

1. 一篇真实 PDF 可以从上传走到报告。
2. 引用获取范围和失败原因透明。
3. 至少一类文本复用证据可准确回到两份 PDF。
4. 用户可以确认、驳回或要求补充材料。
5. 最终报告与界面一致。
6. 临时全文和索引得到明确保留或清理终态。
7. 所有用户可见表述都遵守“异常不等于造假、相似不等于抄袭”。

## 10. 下一轮首个实现切片

下一轮直接完成阶段 0，并尽可能贯通阶段 1 的最小路径：

```text
上传 PDF
  → 生成任务与资产哈希
  → GROBID解析
  → 展示论文元数据、正文结构和引用清单
  → 保存覆盖率
```

不得先开发漂亮仪表盘、总分、复杂模型编排或长期检索基础设施。
