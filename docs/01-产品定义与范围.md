# 产品定义与范围

## 1. 产品定义

SBDC 是论文科研诚信深度检查与证据复核工作台。用户提交一篇博士论文或期刊论文，系统解析论文及其引用关系，即时获取当前任务可合法访问的引用全文，执行多条独立检查管线，并将发现组织成可追溯的证据卡。

产品不做“一键判定造假”。它降低人工审查的检索、定位、交叉核对和证据整理成本。

## 2. 目标用户与核心动作

目标用户包括高校学术委员会、期刊编辑、科研诚信人员、导师和需要投稿前自查的研究者。

用户的核心动作只有六个：

1. 提交待检论文及可选补充材料。
2. 确认解析出的论文信息和引用清单。
3. 启动检查并了解覆盖范围。
4. 查看每个异常的原文与对照证据。
5. 对证据确认、驳回或要求补充材料。
6. 导出可复核的审查报告。

界面围绕上述动作设计，不要求用户理解向量索引、模型路由、Worker 或内部对象。

## 3. 输入证据等级

### L1：论文包

输入 PDF、DOCX 或 LaTeX。可检查：

- 引用范围内的逐字、改写和翻译式文本复用；
- 参考文献真实性、元数据错误、撤稿或更正状态；
- 引用是否支持当前论断；
- 论文内部数字、表格、统计表达和图片异常；
- 论文内部及引用论文之间的图片复用。

### L2：深度数据包

在 L1 基础上增加 CSV、XLSX、统计输出和分析说明。可进一步检查：

- 数据重复、不可能值、字段依赖冲突；
- 表图与原始数据是否一致；
- 主要统计结果能否复算；
- 样本排除和缺失值是否符合论文陈述。

首期不自动执行用户上传的分析代码。

### L3：调查材料包

在 L2 基础上增加实验原图、仪器导出、实验日志及版本记录。可进一步检查数据与图片来源、处理链和时间一致性。

## 4. 默认检查范围

默认范围是待检论文明确列出的参考文献：

1. 提取并规范化引用。
2. 从合法开放渠道获取全文。
3. 只在当前任务空间解析和索引。
4. 对待检论文与这些引用文献进行检查。
5. 任务结束后按已声明的保留策略处理全文和派生产物。

该范围擅长发现：引用后过度复制、引用式改写、引用不支持论断、引用图片复用和引文序列异常。

它不能完整发现从未列入参考文献的来源抄袭。后续可增加“外部来源追查”：仅对用户选择的可疑段落临时检索候选来源，仍不建设长期全文库。

## 5. 输出语言与证据等级

系统对每项发现使用以下处置状态：

- `已验证异常`：存在可复算、可定位或可重复的客观不一致。
- `高风险，需原始材料`：线索明确，但需要原始数据、原图或作者说明。
- `线索不足`：模型或规则找到弱信号，当前证据不足以支持行动。
- `合理复用或误报`：人工确认属于正确引用、固定方法、合法版本演进或其他合理情况。

严重程度与证据可信度分别记录，禁止合并成一个“论文诚信分”。

## 6. 明确不做

- 不自动判定作者主观故意。
- 不把相似度直接称为抄袭率。
- 不因单个统计错误判定数据造假。
- 不绕过付费墙获取全文。
- 不建立共享、长期全文对照库。
- 不把用户论文或原始数据默认发送给第三方模型。
- 首期不执行用户上传的任意代码或宏。

## 7. 产品成功标准

首期成功不以检测器数量衡量，而以完整用户闭环衡量：用户能够上传论文、看到真实覆盖范围、打开一项带原文位置和对照来源的证据、作出复核决定，并导出与界面一致的报告；任务临时材料的最终状态清晰可查。
