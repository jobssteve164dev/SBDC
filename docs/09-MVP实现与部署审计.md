# MVP 实现与部署审计

## 审计结论

当前版本已经形成“上传论文 → 异步解析 → 引用规范化与开放全文获取 → 任务级临时索引 → 连续文本/语义近似/引用支持/可复算统计/PDF 图片区域证据 → 人工裁决 → 报告 → 临时材料清理”的可运行切片。它仍不是全部科研诚信检测能力：跨语言或嵌入式语义召回、更多统计格式、表格数据和原始图片取证尚未实现，页面与报告必须继续显示实际覆盖范围。

## 代码实况

| 范围 | Observed in code | 结论 |
| --- | --- | --- |
| Web | Next.js 提供上传、任务进度、解析结果和 PDF 定位页面 | 首个用户路径已连通 |
| API | FastAPI 提供任务、资产上传、解析触发、结果和文件读取接口 | 接口本身不承担公网会话鉴权 |
| Worker | Celery 调用 GROBID 与 PyMuPDF，结果写入 PostgreSQL 与 MinIO | 依赖业务 Compose 服务和受治理 PostgreSQL |
| 数据 | PostgreSQL 保存任务结构，MinIO 保存任务资产 | 引用全文和任务索引支持清单式清理与失败重试 |
| 鉴权 | Web 使用签名、限时、HttpOnly 会话；Proxy 同时保护页面和 `/backend` | 公网访问统一经过登录边界 |
| 网络 | Compose 只把 Web 的 `3100` 端口绑定到节点回环地址，API 与数据服务仅在内部网络可达 | 公网只能经受治理的 Tunnel 进入，关闭直连旁路 |
| 配置 | 数据库、对象存储、登录和会话密钥均由 `.env` 注入 | `.env` 被 Git 忽略，示例文件只含占位值 |
| 持续验证 | CI 执行 Python 回归、Web 类型检查、生产构建，并验证登录后后端代理 | 不再以“文件存在”代替产品验证 |

## 鉴权边界

- 未登录访问工作台会跳转登录页；原路径仅以站内相对路径保存，拒绝开放重定向。
- 未登录访问 `/backend` 返回 `401`，不会被重写到内部 API。
- 登录凭据采用定时安全比较；成功后签发 12 小时 HMAC 会话，Cookie 使用 `HttpOnly`、`Secure`、`SameSite=Strict`。
- 错误凭据、篡改会话和过期会话均不能进入工作台；退出会清除浏览器中的会话 Cookie。
- 同一公网来源 10 分钟内连续失败 10 次后会暂停登录校验；来源地址取自 Tunnel 覆写的请求头，源站回环绑定使公网不能伪造该头直连。当前仍是单审查者共享入口，不提供账号管理、多角色权限、找回密码或操作审计。

## 部署边界与验收

- 目标节点：`onex-nextterminal`；发布方式：既有 GitOps release 链；公开域名：`sbdc.szlk.uk`。
- 生产入口只通过 Tunnel 指向 Web 回环端口；`/health` 会同时验证登录配置的完整性，配置无效时返回 `503`。
- 发布验收必须同时覆盖：域名可达、登录页可用、匿名页面跳转、匿名后端 `401`、正确登录可进入工作台、容器健康及必需环境变量键存在。
- GitOps release 的签名制品必须包含 Web、API、Worker、Redis、MinIO、GROBID 的全部业务运行镜像；生产 PostgreSQL 由 GitOps 数据库池独立创建、绑定并注入连接，不能进入业务 Compose 制品。schema 迁移由根 Compose 声明的 `api` 迁移入口执行，不发布独立迁移容器。切换完成前保留旧数据库作为回滚源，业务发布不得删除它。目标节点只消费受治理的制品，不直连公共镜像仓库补拉依赖。GROBID 首次加载和预热消耗较大，但不应通过跳过解析来伪装部署成功。

## 剩余产品缺口

1. 当前文本来源检查包含连续词面重合和可解释词项向量语义近似候选；尚未接入 BGE-M3/FAISS 跨语言或翻译式改写检索。
2. 引用论断核对已覆盖引用序号绑定、文本/数值对齐和常见方向冲突候选；复杂蕴含关系、撤稿与更正核验仍未进入统一证据闭环。
3. 当前仅复算 PDF 中可直接提取输入值的统计表达式，并对 PDF 内嵌位图做局部感知指纹筛查；更多统计格式、表格数据和原始图片取证仍需后续按同一 `EvidenceItem` 契约接入。
4. 当前登录适合单一受控审查入口；多人正式使用前需要身份账户、权限角色、登录防爆破和操作审计。

引用来源处理按任务限制全文数量、总字节、总页数、总字符、索引大小和候选块比较次数；达到比较上限时，前台与报告披露实际覆盖，不对未处理部分作结论。深度检查失败后也可直接清理已登记的临时引用资产，不要求先生成报告。

这些缺口不阻止当前解析切片作为受限 MVP 上线，但限制了它能对外承诺的功能范围。
