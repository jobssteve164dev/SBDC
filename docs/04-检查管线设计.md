# 检查管线设计

## 1. 总管线

```text
接收材料
  → 文件验证与哈希
  → 文档解析与坐标归一
  → 引用解析与用户确认
  → 开放全文获取
  → 任务级临时索引
  → 多检测器并行检查
  → 证据归并与去重
  → 人工复核
  → 报告
  → 临时资产保留或清理
```

任何阶段失败都保留真实覆盖信息。例如 80 篇引用中只取得 52 篇全文，报告必须写明 `52/80`，不能声称完成了全引用查重。

## 2. 文本复用检查

### 2.1 预处理

- 按章节、段落、句子切分，但保留原始字符偏移和 PDF 页码坐标。
- 规范化 Unicode、软换行、连字符断词和空白。
- 标记直接引语、引用标记、参考文献、公式、表格、图注和代码块。
- 方法章节不跳过，但使用单独基线，防止通用方法短语淹没真正异常。

### 2.2 候选召回

- 字面召回：字符和词 n-gram、Winnowing、MinHash。
- 语义召回：BGE-M3段落向量和 FAISS。
- 论文级与引用序列信号只用于调整候选优先级。

### 2.3 精确对齐与解释

- 使用局部序列对齐确定待检与来源片段。
- 计算覆盖长度、连续性、改写程度和引文邻近关系。
- 区分正确直接引用、正确转述、引用但过度复制、无归属复用和低信息套话。
- 输出双栏原文、页码、段落、来源 DOI、相同内容高亮和省略上下文。

## 3. 引文检查

每条参考文献依次检查：

1. DOI或其他稳定标识是否存在。
2. 题名、作者、年份、期刊是否与权威元数据一致。
3. 是否有撤稿、更正或表达关注记录。
4. 正文引用标记是否正确关联参考文献。
5. 引用附近的可核验论断是什么。
6. 被引全文是否包含支持或反对该论断的证据。
7. 是否存在异常二手引用、引用簇或引用序列复制信号。

“全文不可获得”和“没有找到支持证据”是两个不同状态，不能混淆。

## 4. 统计与数据检查

### PDF-only

- 复算 p 值、效应量和置信区间。
- 检查均值、标准差、样本量和自由度的数学一致性。
- 检查表格合计、百分比、组间样本量和缺失值。
- 对摘要、正文、表格和图中的同一指标进行跨位置一致性检查。
- 运行 GRIM、GRIMMER和适用的 SPRITE 分布可实现性测试。

### 提供原始数据时

- 模式、类型、取值范围和唯一性检查。
- 重复行、近重复记录、时间顺序和字段依赖冲突。
- 分组间异常相似、尾数偏好和异常分布信号。
- 按受控、项目内置分析规格复算关键表格和结论。
- 对样本排除、缺失值处理和论文陈述进行核对。

统计异常卡必须写清假设，例如量表范围、舍入方式和样本量；假设不明时状态只能是待复核。

## 5. 图片检查

1. 优先提取 PDF 内嵌原图，同时保存页面渲染版本。
2. 识别复合图并拆分面板，保留面板到页码和图号的映射。
3. 用感知哈希和 SSCD寻找论文内部及引用论文中的近重复候选。
4. 用局部特征和 RANSAC验证裁剪、旋转、缩放、镜像关系。
5. 运行局部复制和拼接异常检测，输出可视区域而不是单一分数。
6. 对图表反向提取的数值与表格、正文进行交叉检查。

没有原图时只能报告“发表图片存在差异”；不能认证图片真实性。

## 6. 方法、伦理和版本一致性

- 伦理审批号、临床试验注册号和文内描述的一致性。
- 样本量计算、计划结局和实际分析的一致性。
- 数据、代码和附件链接是否存在且与声明相符。
- 学位论文、预印本、期刊版和更正版之间的样本量、结局和主要数字变化。
- 同一研究数据重复发表但缺少适当说明的风险信号。

## 7. 证据归并

多个检测器可能指向同一问题。归并规则按“待检位置 + 来源 + 问题类型”聚合，保留全部检测器输出，但只向用户呈现一张证据卡。任何聚合不得提高原始证据强度。

## 8. 评测指标

- 引用解析：参考文献解析准确率、DOI解析率、正文引用关联准确率。
- 文本检索：Recall@K；片段对齐：span precision、recall、F1。
- 误报：每百页需人工驳回的证据数，按章节和问题类型分层。
- 图片：候选召回率、几何验证准确率、区域级指标。
- 统计：适用表达式覆盖率、复算准确率、假设缺失率。
- 产品闭环：用户定位一个问题所需时间、证据裁决率、报告与界面一致率。

不设置“造假识别准确率”，因为系统不承担造假定性。
