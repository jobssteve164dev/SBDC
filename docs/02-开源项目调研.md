# 开源项目调研

调研日期：2026-08-26。下一轮引入依赖前必须再次核对最新版本、许可证、模型权重条款和维护状态。

## 1. 推荐复用

| 项目 | 能力 | 采用方式 | 主要边界 |
|---|---|---|---|
| [GROBID](https://github.com/grobidOrg/grobid) | 将学术 PDF 解析为 TEI XML，提取章节、引用上下文、参考文献、图表和坐标 | 独立 Docker 服务，作为 PDF 结构化底座 | 解析不是百分之百准确；需要人工确认低置信引用 |
| [Crossref REST API](https://www.crossref.org/documentation/retrieve-metadata/rest-api/) | DOI、书目信息、引用、撤稿和更正元数据 | 引用身份规范化和状态查询 | 元数据覆盖依赖出版方提交，不能当全文来源 |
| [OpenAlex](https://developers.openalex.org/) | 开放学术图谱、论文身份、引用关系和开放位置 | 补充身份解析与候选开放位置 | 位置可读不等于可任意再分发，必须检查具体许可 |
| [Unpaywall](https://unpaywall.org/api) | 根据 DOI 查找开放获取副本 | 开放全文定位链的一环 | 只提供位置与开放状态，不保证解析质量 |
| [CORE API](https://core.ac.uk/services/api) | 开放获取论文元数据与全文 | 合法全文获取链的一环 | 遵守 API 合同、速率与内容许可 |
| [BGE-M3](https://huggingface.co/BAAI/bge-m3) | 多语言、多粒度语义检索 | 中英文段落级候选召回 | 语义相近不是抄袭证据，必须精确对齐复核 |
| [FAISS](https://github.com/facebookresearch/faiss) | 本地密集向量相似搜索 | 每个任务建立临时索引 | 不承担持久化、权限或生命周期治理 |
| [statcheck](https://github.com/MicheleNuijten/statcheck) | 识别特定格式统计检验并复算 p 值 | 隔离 R Worker | 主要适配完整的 NHST 报告格式，只发现报告不一致 |
| [scrutiny](https://github.com/lhdjung/scrutiny) | GRIM、GRIMMER 等一致性测试 | 隔离 R Worker并锁定已验证版本 | 对量表、取值范围和舍入假设敏感 |
| [rsprite2](https://github.com/LukasWallrich/rsprite2) | 根据汇总统计重建可能分布 | 隔离 R Worker | 只回答数学可实现性，不回答数据是否真实 |
| [SSCD](https://github.com/facebookresearch/sscd-copy-detection) | 对裁剪、压缩和变化后的图片副本进行检索 | 图片指纹与候选召回 | 需要针对科学图片做阈值标定和几何复核 |
| [BINDER](https://github.com/HMS-IDAC/BINDER) | 生物医学近重复图片数据集与基线 | 图片模块评测语料 | 领域和变换分布有限，不能作为唯一验收集 |

## 2. 参考而不直接依赖

### HyPlag

[HyPlag](https://gipplab.uni-goettingen.de/projects/hyplag/) 同时分析文本、引用序列、公式和图片，并提供双文档证据视图。它最值得复用的是多模态证据组织方式，而不是把整个研究系统直接嵌入生产。

### ELIS

[ELIS](https://github.com/researchintegrity/elis) 已组合 PDF 图片提取、面板拆分、相似图片检索、copy-move 和来源分析。项目主许可证为 AGPLv3，且其集成模块可能有不同或非商业条款。首期只参考模块边界，逐个选择许可证清晰的组件。

### OpenCitations CEC

[Citation Extraction and Classifier](https://github.com/opencitations/cec) 可参考其正文引用上下文提取与引用功能分类设计。首期由 GROBID 提供基本引用上下文，后续再决定是否接入分类器。

### SPECTER2

[SPECTER2](https://github.com/allenai/SPECTER2) 适合题名、摘要和整篇论文层面的学术相似性。SBDC 首期的核心对象是中英文段落，因此先采用 BGE-M3；如需要论文级候选排序，再增加 SPECTER2。

## 3. 不作为正文查重底座

- JPlag 主要面向程序源码抄袭。它可以以后用于论文随附源码，但不承担论文正文检测。
- 小型“一站式论文造假检测”仓库只能作为思路来源，不能仅凭 README 声明进入生产依赖。
- 大模型 AI 文本检测不作为科研诚信证据；其误差和可解释性不足以支持定性。

## 4. 评测资源

- PAN 文本复用任务：用于逐字、改写和生成式改写的检索与片段对齐评测。使用前核对每届语料的研究用途及再分发限制。
- BINDER：用于科学图片近重复候选召回评测。
- 自建金标集：必须包含正确引用、通用方法套话、作者合法版本演进、正文复制、翻译改写、引用不支持和无法获取全文等真实边界。

## 5. 依赖准入门禁

每个依赖进入正式清单前记录：代码许可证、模型权重许可证、数据许可证、商业使用限制、网络调用、是否上传用户内容、资源需求、固定版本、维护状态和替代方案。代码开源不代表模型或数据也可用于目标场景。
